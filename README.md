Escreva para mim aqui que este projeto esta em desenvolvimento e que foi gerado no Visual Studio pelo GitHub Copilot Chat.
Solicitei ao Copilot que com base no código fonte da API ASP Net Core aberto no Visual Studio que gerasse todo o código fonte em JAVA com as mesmas funcionalidade e mesmas regra de negosio.

O Resultado foi que o código fonte em JAVA precisou de muitas alterações básicas, como por exemplo, ajuste nas entidades que ficara com tipos diferentes da do ASP Net Core,
e com isso as aplicações que tenho de Frontend em Angula e React não conseguiram fazer requisições de inicio, sendo necessário ajustes.
Também não seguiu a mesma regra de negocio e o Copilot gerou regras por conta própria ou por erro mesmo como por exemplo na troca de senha do primeiro login.
